## arrays

Collection helpers: set algebra, grouping, chunking, sorting, sampling.

```ts
import { … } from 'tinkjs/arrays';
```

| Export                     | Description                                                                                                                                                                                                                                                                 |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `contains`                 | Check if an array contains a value, using SameValueZero equality (so `NaN` is found and `0` matches `-0`).                                                                                                                                                                  |
| `first`                    | Get the first item in an array.                                                                                                                                                                                                                                             |
| `last`                     | Get the last item in an array.                                                                                                                                                                                                                                              |
| `flatten`                  | Flatten an array by exactly one level, like `Array.prototype.flat()` (holes in sparse arrays are skipped).                                                                                                                                                                  |
| `flattenDeep`              | Recursively flatten nested arrays of any depth, like `Array.prototype.flat(Infinity)` (holes are skipped).                                                                                                                                                                  |
| `removeDuplicates`         | Remove duplicates from an iterable (SameValueZero equality), keeping the first occurrence of each value.                                                                                                                                                                    |
| `union`                    | Get the union of two iterables: every distinct value from `a`, then every distinct value of `b` not already in `a`.                                                                                                                                                         |
| `intersection`             | Get the intersection of two iterables: the distinct values of `a` that also appear in `b`.                                                                                                                                                                                  |
| `difference`               | Get the difference of two iterables: the distinct values of `a` that do not appear in `b`.                                                                                                                                                                                  |
| `symmetricDifference`      | Get the symmetric difference of two iterables: the distinct values that appear in exactly one of them.                                                                                                                                                                      |
| `isSubset`                 | Check whether every value of `subset` also appears in `superset` (SameValueZero equality).                                                                                                                                                                                  |
| `chunk`                    | Split an array into consecutive chunks of `size` items; only the last chunk may be shorter.                                                                                                                                                                                 |
| `compact`                  | Remove every falsy value (`false`, `null`, `undefined`, `0`, `-0`, `NaN`, `''`, `0n`) from an array.                                                                                                                                                                        |
| `range`                    | Create an array of numbers progressing from `start` up to, but not including, `end`, with Python `range` semantics.                                                                                                                                                         |
| `zip`                      | Combine arrays element-wise into tuples, truncating to the length of the shortest array.                                                                                                                                                                                    |
| `groupBy`                  | Group the items of an array by the key returned by `keyFn`, preserving input order within each group.                                                                                                                                                                       |
| `keyBy`                    | Index the items of an array by the key returned by `keyFn`; when several items share a key, the last one wins.                                                                                                                                                              |
| `countBy`                  | Count the items of an array per key returned by `keyFn`.                                                                                                                                                                                                                    |
| `partition`                | Split an array in two: the items matching a type-guard `predicate`, and the others.                                                                                                                                                                                         |
| `uniqueBy`                 | Remove items whose key (as returned by `keyFn`, compared with SameValueZero) was already seen, keeping the first occurrence.                                                                                                                                                |
| `sortBy`                   | Return a sorted copy of an array, ordered by the key `selector` returns for each item.                                                                                                                                                                                      |
| `shuffle`                  | Return a shuffled copy of an array using the Fisher–Yates algorithm (the input is not mutated).                                                                                                                                                                             |
| `sample`                   | Pick a random item from an array.                                                                                                                                                                                                                                           |
| `take`                     | Return the first `n` items of an array (or all of them when it is shorter).                                                                                                                                                                                                 |
| `drop`                     | Return an array without its first `n` items.                                                                                                                                                                                                                                |
| `unzip`                    | Split an array of tuples into one array per tuple position: the inverse of `zip`.                                                                                                                                                                                           |
| `windowed`                 | Return the sliding windows of `size` consecutive items, starting every `step` items.                                                                                                                                                                                        |
| `pairwise`                 | Return every pair of adjacent items: `[a[0], a[1]], [a[1], a[2]], ...` (empty for arrays with fewer than 2 items).                                                                                                                                                          |
| `minBy`                    | Return the item with the SMALLEST key, using the same ordering rules as `sortBy` (numbers/bigints numerically and before strings, strings by UTF-16 code units, `Date`s by timestamp).                                                                                      |
| `maxBy`                    | Return the item with the LARGEST key, using the same ordering rules as `sortBy` (numbers/bigints numerically and before strings, strings by UTF-16 code units, `Date`s by timestamp).                                                                                       |
| `sumBy`                    | Add up the numbers returned by `selector` for each item, using compensated (Neumaier) summation like `sum` from the math module (same algorithm, same result), so the rounding error does not grow with the number of items.                                                |
| `move`                     | Return a copy of an array with the item at `from` moved to position `to` (the input is not mutated).                                                                                                                                                                        |
| `insertAt`                 | Return a copy of an array with `items` inserted before position `index` (the input is not mutated).                                                                                                                                                                         |
| `removeAt`                 | Return a copy of an array without the `count` items starting at `index` (the input is not mutated).                                                                                                                                                                         |
| `sortedIndex`              | Find, by binary search (O(log n)), the LOWEST index at which `value` can be inserted into `sortedArray` keeping it sorted (before any equal items).                                                                                                                         |
| `binarySearch`             | Find the index of `value` in `sortedArray` by binary search (O(log n)); with duplicates, the LOWEST matching index is returned.                                                                                                                                             |
| `cartesianProduct`         | Return the cartesian product of the given arrays: every tuple taking one item from each array, in lexicographic order (the LAST array varies fastest).                                                                                                                      |
| `intersperse`              | Return a copy of an array with `separator` inserted between every two consecutive items.                                                                                                                                                                                    |
| `differenceBy`             | Like `difference`, but items are compared by the key `keyFn` returns (SameValueZero): the items of `a` whose key is not the key of any item of `b`, keeping only the FIRST item of `a` per key.                                                                             |
| `intersectionBy`           | Like `intersection`, but items are compared by the key `keyFn` returns (SameValueZero): the items of `a` whose key is also the key of an item of `b`, keeping only the FIRST item of `a` per key.                                                                           |
| `diffSequences`            | Computes a minimal edit script turning sequence `a` into sequence `b`: a list of `'equal'`, `'delete'` and `'insert'` operations (see `DiffOperation`) with the smallest possible number of deletions plus insertions.                                                      |
| `longestCommonSubsequence` | Computes a longest common subsequence of `a` and `b`: the longest list of elements that appear in both, in the same relative order (not necessarily contiguously).                                                                                                          |
| `unionBy`                  | Like `union`, but items are compared by the key `keyFn` returns (SameValueZero): every item of `a`, then of `b`, whose key was not seen before, so only the FIRST item per key is kept.                                                                                     |
| `symmetricDifferenceBy`    | Like `symmetricDifference`, but items are compared by the key `keyFn` returns (SameValueZero): the items of `a` whose key is not the key of any item of `b`, followed by the items of `b` whose key is not the key of any item of `a`, keeping only the FIRST item per key. |
| `uniqueWith`               | Remove the items `equals` to an earlier item, keeping the first occurrence: `removeDuplicates` with a custom equality, for values that have no identity key (e.g. points within a tolerance).                                                                               |
| `unionWith`                | `union` with a custom equality: every item of `a`, then of `b`, not `equals` to an item already kept (first occurrence wins).                                                                                                                                               |
| `differenceWith`           | `difference` with a custom equality: the items of `a` not `equals` to any item of `b`, keeping only the first of several items of `a` that are `equals` to each other.                                                                                                      |
| `intersectionWith`         | `intersection` with a custom equality: the items of `a` `equals` to some item of `b`, keeping only the first of several items of `a` that are `equals` to each other.                                                                                                       |
| `orderBy`                  | Return a sorted copy of an array, ordered by several keys: by the first selector's key, then items with equal first keys by the second selector's key, and so on, each key in its own direction.                                                                            |
| `takeFirstBy`              | Return the `n` first items of `sortBy(array, selector, order)` without sorting the whole array: a bounded heap selects them in O(length · log n), then only they are sorted.                                                                                                |
| `nthBy`                    | Return the item at position `index` of `sortBy(array, selector, order)` without sorting the whole array (a bounded heap of `position + 1` items, O(length · log position)): `0` is the first ranked item, `1` the second...                                                 |
| `sortedIndexBy`            | Find, by binary search (O(log n) selector calls), the LOWEST index at which `value` can be inserted into `sortedArray` keeping it sorted by the key `selector` returns (before any items with an equal key).                                                                |
| `sortedLastIndexBy`        | Like `sortedIndexBy`, but returns the HIGHEST insertion index (after any items with an equal key), which keeps insertion order among equal keys when used to insert.                                                                                                        |
| `sortedLastIndex`          | Find, by binary search (O(log n)), the HIGHEST index at which `value` can be inserted into `sortedArray` keeping it sorted (after any equal items): the upper-bound counterpart of `sortedIndex`.                                                                           |
| `takeLast`                 | Return the last `n` items of an array (or all of them when it is shorter).                                                                                                                                                                                                  |
| `dropLast`                 | Return an array without its last `n` items.                                                                                                                                                                                                                                 |
| `takeLastWhile`            | Return the longest suffix of an array whose items all match `predicate`, scanning from the end and stopping at the first item that does not match.                                                                                                                          |
| `dropLastWhile`            | Return an array without its longest suffix whose items all match `predicate` (scanning from the end, stopping at the first item that does not match).                                                                                                                       |
| `chunkBy`                  | Split an array into runs of ADJACENT items with the same key (compared with SameValueZero, so `NaN` keys group together), like Python's `itertools.groupby`: unlike `groupBy`, a key that comes back after another one starts a new run.                                    |
| `splitWhen`                | Split an array in two at the first item matching `predicate`: the items before it, and the rest (starting with that item).                                                                                                                                                  |
| `swap`                     | Return a copy of an array with the items at positions `i` and `j` exchanged (the input is not mutated).                                                                                                                                                                     |
| `rotate`                   | Return a copy of an array rotated by `k` positions (the input is not mutated): a positive `k` moves every item `k` places towards the END, the last items wrapping around to the front (like Python's `deque.rotate`); a negative `k` rotates towards the start.            |
| `toggle`                   | Return a copy of an array where `item` is removed if present, or appended otherwise: the state change of a checkbox list or tag picker.                                                                                                                                     |
| `toArray`                  | Normalize a value that may be a single item, an array of items, or nothing, into a fresh array (lodash's `castArray`).                                                                                                                                                      |
| `zipObject`                | Build an object from a list of keys and a list of values: `{ [keys[i]]: values[i] }`, like `Object.fromEntries(zip(keys, values))`.                                                                                                                                         |
| `zipWith`                  | Combine arrays element-wise with `fn`: `fn(a[i], b[i], ...)` for every index, truncating to the length of the SHORTEST array like `zip` (lodash pads the shorter arrays with `undefined` instead, which `fn`'s parameter types would not reveal).                           |
| `sampleSize`               | Return `n` distinct random items of an array (sampling WITHOUT replacement: positions are distinct, so equal values may repeat only if the input repeats them).                                                                                                             |
| `averageBy`                | Return the mean of the numbers `selector` returns for each item, added up with compensated summation like `sumBy` (so `0.1`, `0.2`, `0.3` average to exactly `0.2`).                                                                                                        |
| `medianBy`                 | Return the median of the numbers `selector` returns for each item (the mean of the two middle values for an even count), with the semantics of `median` from the math module: keys are converted once with unary `+`, and the result does not depend on the item order.     |
| `combinations`             | Return every combination of `k` items of an array (subsets of `k` POSITIONS, items in input order), in lexicographic order of positions, like Python's `itertools.combinations`.                                                                                            |
| `permutations`             | Return every arrangement of `k` items of an array (ordered selections of `k` distinct POSITIONS), in lexicographic order of positions, like Python's `itertools.permutations`.                                                                                              |
| `powerSet`                 | Return every subset of an array (`2 ** length` of them, items in input order), in binary-counting order: item `i` is in subset `m` when bit `i` of `m` is set, so `[]` comes first and the whole array last.                                                                |

## objects

Shallow/deep cloning, merging, equality, path access and object reshaping.

```ts
import { … } from 'tinkjs/objects';
```

| Export                   | Description                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `merge`                  | Shallowly merges one or more source objects into a NEW object, left to right (later keys win, like `{ ...target, ...a, ...b }`).                                                                                                                                                                                                                                                                                                        |
| `clone`                  | Creates a shallow copy of a value.                                                                                                                                                                                                                                                                                                                                                                                                      |
| `hasProperty`            | Determines whether an object has an OWN property with the given key (inherited properties such as `toString` do not count).                                                                                                                                                                                                                                                                                                             |
| `getProperty`            | Gets the value of a property of an object (own or inherited, e.g. a class getter, or a string's `length`).                                                                                                                                                                                                                                                                                                                              |
| `setProperty`            | Sets the value of a property of an object.                                                                                                                                                                                                                                                                                                                                                                                              |
| `deleteProperty`         | Deletes a property from an object.                                                                                                                                                                                                                                                                                                                                                                                                      |
| `getPropertyNames`       | Gets the names of ALL own string-keyed properties of an object (`Object.getOwnPropertyNames`), including NON-enumerable ones (e.g. arrays include `'length'`).                                                                                                                                                                                                                                                                          |
| `isEmpty`                | Determines whether a value is empty.                                                                                                                                                                                                                                                                                                                                                                                                    |
| `pick`                   | Creates a new object with only the given keys.                                                                                                                                                                                                                                                                                                                                                                                          |
| `omit`                   | Creates a new object with every own enumerable (string and symbol) property except the given keys.                                                                                                                                                                                                                                                                                                                                      |
| `mapValues`              | Creates a new object with the same own enumerable (string and symbol) keys, whose values are the results of `fn`.                                                                                                                                                                                                                                                                                                                       |
| `mapKeys`                | Creates a new object with the same values, whose keys are the results of `fn`.                                                                                                                                                                                                                                                                                                                                                          |
| `invert`                 | Creates a new object whose keys are the values of `object` and whose values are the (string) keys.                                                                                                                                                                                                                                                                                                                                      |
| `getFromObjectByKeys`    | Safely reads a nested value through a dot-separated path (array elements are addressed with numeric segments: `'list.0.id'`).                                                                                                                                                                                                                                                                                                           |
| `setInObjectByKeys`      | Sets a nested value through a dot-separated path.                                                                                                                                                                                                                                                                                                                                                                                       |
| `updateInObjectByKeys`   | IMMUTABLE counterpart of `setInObjectByKeys`: returns a NEW root in which the value at the dot-separated path is replaced by `valueOrUpdater` (or, when it is a function, by `valueOrUpdater(currentValue)`).                                                                                                                                                                                                                           |
| `omitInObjectByKeys`     | IMMUTABLE counterpart of `deleteFromObjectByKeys`: returns a NEW root without the own property at the dot-separated path, copying only the plain objects and arrays on the path (structural sharing).                                                                                                                                                                                                                                   |
| `toPath`                 | Parses a property path written in JavaScript accessor syntax into its segments: dot-separated names (`a.b`) and brackets holding a canonical array index (`[0]`) or a quoted key (`['b.c']`, `["x"]`, with `\\`, `\'` and `\"` as the only escapes).                                                                                                                                                                                    |
| `deepClone`              | Creates a deep copy of a value without using `structuredClone`.                                                                                                                                                                                                                                                                                                                                                                         |
| `deepMerge`              | Deeply merges plain objects into a NEW object, left to right (later sources win).                                                                                                                                                                                                                                                                                                                                                       |
| `deepMergeWith`          | `deepMerge` with options: an array strategy and a customizer.                                                                                                                                                                                                                                                                                                                                                                           |
| `defaults`               | Fills the MISSING keys of a copy of `target` from `sources`: a key keeps the first value that is not `undefined`, looking at the target first, then each source in order (lodash `defaults`, without mutating anything).                                                                                                                                                                                                                |
| `defaultsDeep`           | `defaults` that also fills nested plain objects recursively: a plain object of the target and a plain object of a source at the same key are filled key by key; any other present value (arrays included) is kept as is.                                                                                                                                                                                                                |
| `defaultsWith`           | `defaults` / `defaultsDeep` with options, making explicit the choices the popular libraries disagree on.                                                                                                                                                                                                                                                                                                                                |
| `isEqual`                | Deep structural equality.                                                                                                                                                                                                                                                                                                                                                                                                               |
| `isEqualWith`            | `isEqual` with a customizer consulted for every compared pair of non-identical values (`Object.is`: identical values are always equal, so `0` and `-0` do reach it), the roots included, before the default rules: `customizer(a, b, { key, path, parentA, parentB, equals })` returns `true` or `false` to settle that pair, or `undefined` to fall back to `isEqual`'s rules (whose nested comparisons consult the customizer again). |
| `isMatch`                | Deep PARTIAL match: whether `value` has every key of `pattern` with a matching value, recursively for plain objects.                                                                                                                                                                                                                                                                                                                    |
| `shallowEqual`           | One-level equality: `true` when the values are SameValueZero-equal, or are objects of the same prototype and kind whose own members are SameValueZero-equal (no deep comparison, O(n)).                                                                                                                                                                                                                                                 |
| `deepFreeze`             | Recursively freezes an object and every object reachable through its own (string and symbol) data properties, as well as `Map` keys/values and `Set` members.                                                                                                                                                                                                                                                                           |
| `typedKeys`              | `Object.keys` with a precise return type: the OWN ENUMERABLE STRING keys of an object (symbol keys and inherited keys are excluded, numeric keys are returned as strings).                                                                                                                                                                                                                                                              |
| `typedEntries`           | `Object.entries` with a precise return type: `[key, value]` pairs for the OWN ENUMERABLE STRING keys of an object (symbol keys and inherited keys are excluded).                                                                                                                                                                                                                                                                        |
| `typedFromEntries`       | `Object.fromEntries` with a precise return type: builds a new object from `[key, value]` pairs (later duplicates win).                                                                                                                                                                                                                                                                                                                  |
| `pickBy`                 | Creates a new object with the own enumerable (string and symbol) properties for which `predicate` returns true.                                                                                                                                                                                                                                                                                                                         |
| `omitBy`                 | Creates a new object without the own enumerable (string and symbol) properties for which `predicate` returns true (the complement of `pickBy`).                                                                                                                                                                                                                                                                                         |
| `compactObject`          | Creates a SHALLOW copy of an object without the own properties whose value is `undefined`.                                                                                                                                                                                                                                                                                                                                              |
| `flattenObject`          | Flattens nested plain objects and arrays into a single-level record mapping each LEAF path to its value.                                                                                                                                                                                                                                                                                                                                |
| `unflattenObject`        | Rebuilds a nested object from a flat record of paths (the inverse of `flattenObject`).                                                                                                                                                                                                                                                                                                                                                  |
| `hasInObjectByKeys`      | Checks whether a dot-separated path exists in an object: it is `true` exactly when `getFromObjectByKeys` resolves the path to a property (whose value may be `undefined`) rather than falling back to the default value.                                                                                                                                                                                                                |
| `deleteFromObjectByKeys` | Deletes the property at a dot-separated path.                                                                                                                                                                                                                                                                                                                                                                                           |
| `diff`                   | Computes the structural differences between two trees of plain objects and arrays, as dot-separated paths (array elements use numeric segments: `'list.0'`).                                                                                                                                                                                                                                                                            |
| `findKey`                | Returns the first own enumerable string key (in `Object.keys` order) whose value satisfies `predicate`.                                                                                                                                                                                                                                                                                                                                 |
| `findEntry`              | Returns the first `[key, value]` own enumerable string-keyed entry whose value satisfies a type-guard `predicate`, narrowed.                                                                                                                                                                                                                                                                                                            |
| `mapEntries`             | Creates a new object by mapping every own enumerable string-keyed entry (in `Object.keys` order) to a new `[key, value]` pair.                                                                                                                                                                                                                                                                                                          |
| `sortKeys`               | Returns a copy of a plain object (or an array) whose own enumerable string keys are inserted in sorted order, for stable output and readable diffs.                                                                                                                                                                                                                                                                                     |
| `evolve`                 | Returns a copy of a plain object (or an array) in which the values of the keys named in `transforms` are replaced: a function receives the current value and returns the new one; a nested plain object of transforms applies recursively to a nested plain object or array.                                                                                                                                                            |
| `transformKeysDeep`      | Returns a deep copy of the plain objects and arrays of `value` in which every own enumerable STRING key of every plain object is renamed by `fn` (symbol keys are kept).                                                                                                                                                                                                                                                                |
| `toCamelCaseKeys`        | Deeply renames the keys of plain objects (also inside arrays) to camelCase with `strings/toCamelCase`, the same word splitter as every case function of tink (acronyms: `XMLHttpRequest` → `xmlHttpRequest`; digits stay attached: `version2`), so the result TYPE (`CamelCaseKeys`) matches the runtime keys exactly for ASCII keys.                                                                                                   |
| `toSnakeCaseKeys`        | Deeply renames the keys of plain objects (also inside arrays) to snake_case with `strings/toSnakeCase`; same rules as `toCamelCaseKeys`.                                                                                                                                                                                                                                                                                                |
| `toKebabCaseKeys`        | Deeply renames the keys of plain objects (also inside arrays) to kebab-case with `strings/toKebabCase`; same rules as `toCamelCaseKeys`.                                                                                                                                                                                                                                                                                                |
| `stableStringify`        | Serializes a value into a DETERMINISTIC string: two values give the same string exactly when they hold the same data, whatever the insertion order of their keys or `Map`/`Set` entries, which makes the result usable as a cache key, a memoization key or the input of `hash`.                                                                                                                                                        |
| `hash`                   | Hashes a value: the 53-bit cyrb53 hash of its `stableStringify` encoding, so equal data gives equal hashes whatever the key order.                                                                                                                                                                                                                                                                                                      |

## guards

Runtime type predicates that narrow `unknown` values, composable into path-aware, Standard Schema-compatible validators.

```ts
import { … } from 'tinkjs/guards';
```

| Export                      | Description                                                                                                                                                                                                                                              |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `isObject`                  | Checks whether a value is a non-null object (`typeof value === 'object'`).                                                                                                                                                                               |
| `isArray`                   | Checks whether a value is an array (works across realms, uses `Array.isArray`).                                                                                                                                                                          |
| `isFunction`                | Checks whether a value is callable (functions, arrow functions, classes, async and generator functions).                                                                                                                                                 |
| `isString`                  | Checks whether a value is a primitive string (boxed `String` objects are not strings here).                                                                                                                                                              |
| `isNumber`                  | Checks whether a value is a primitive number.                                                                                                                                                                                                            |
| `isBoolean`                 | Checks whether a value is a primitive boolean.                                                                                                                                                                                                           |
| `isUndefined`               | Checks whether a value is `undefined`.                                                                                                                                                                                                                   |
| `isNull`                    | Checks whether a value is `null`.                                                                                                                                                                                                                        |
| `isSymbol`                  | Checks whether a value is a symbol.                                                                                                                                                                                                                      |
| `isBigInt`                  | Checks whether a value is a bigint.                                                                                                                                                                                                                      |
| `isPromise`                 | Checks whether a value is promise-like: a native `Promise` OR any thenable (an object or function with a callable `then` property), which is what `await` accepts.                                                                                       |
| `isRegExp`                  | Checks whether a value is a genuine `RegExp` (it has the internal regexp slots).                                                                                                                                                                         |
| `isError`                   | Checks whether a value is an `Error` (including subclasses such as `TypeError`).                                                                                                                                                                         |
| `isDate`                    | Checks whether a value is a `Date` instance.                                                                                                                                                                                                             |
| `isMap`                     | Checks whether a value is a genuine `Map` (brand check: cross-realm and subclass instances pass; objects that merely inherit from `Map.prototype`, and proxies, fail).                                                                                   |
| `isSet`                     | Checks whether a value is a genuine `Set` (brand check: cross-realm and subclass instances pass; objects that merely inherit from `Set.prototype`, and proxies, fail).                                                                                   |
| `isWeakMap`                 | Checks whether a value is a genuine `WeakMap` (brand check: cross-realm and subclass instances pass; objects that merely inherit from `WeakMap.prototype`, and proxies, fail).                                                                           |
| `isWeakSet`                 | Checks whether a value is a genuine `WeakSet` (brand check: cross-realm and subclass instances pass; objects that merely inherit from `WeakSet.prototype`, and proxies, fail).                                                                           |
| `isNil`                     | Checks whether a value is `null` or `undefined`.                                                                                                                                                                                                         |
| `isDefined`                 | Checks whether a value is neither `null` nor `undefined`, narrowing `T` to `NonNullable<T>`.                                                                                                                                                             |
| `isTruthy`                  | Checks whether a value is truthy, narrowing it to `Exclude<T, Falsy>`: unlike `array.filter(Boolean)`, `array.filter(isTruthy)` narrows the element type.                                                                                                |
| `isFalsy`                   | Checks whether a value is falsy (`false`, `0`, `-0`, `0n`, `''`, `null`, `undefined` or `NaN`), narrowing it to `FalsyPart`: `string \| undefined` becomes `'' \| undefined`, and a wide `number` stays `number` (it may be `NaN`).                      |
| `isPlainObject`             | Checks whether a value is a plain object: an object whose prototype is exactly `Object.prototype` or `null` (object literals, `Object.create(null)`, `JSON.parse` output).                                                                               |
| `isPrimitive`               | Checks whether a value is a primitive (`string`, `number`, `bigint`, `boolean`, `symbol`, `null` or `undefined`).                                                                                                                                        |
| `isIterable`                | Checks whether a value implements the iterable protocol (`value[Symbol.iterator]` is a function).                                                                                                                                                        |
| `isAsyncIterable`           | Checks whether a value implements the async iterable protocol (`value[Symbol.asyncIterator]` is a function).                                                                                                                                             |
| `isFiniteNumber`            | Checks whether a value is a finite number (excludes `NaN` and `±Infinity`).                                                                                                                                                                              |


| Export          | Description                                                                                                                                                                                                                                               |

| Export       | Description                                                                                                                                                                                                                                                                                                                  |
