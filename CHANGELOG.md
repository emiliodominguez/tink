# Changelog

## 1.6.0 (unreleased)

The `store`/`cache` pass of 1.5.0, extended to every module and repeated until each came back clean: every module was audited for safety (prototype pollution, hostile input sizes), for state left inconsistent after a throw or a re-entrant call, for bugs and for speed, against references (Chrome's CSS engine, parse5, `node:crypto`, `node:zlib`, `node:net`, `node:path`, node-semver, Python's `str.title()`, exact BigInt arithmetic, `Intl` in 418 time zones) and with differential fuzzing against 1.5.0. Every fix comes with a regression test that fails on 1.5.0; every speed-up was measured against the 1.5.0 build in the same process.

**Added.**

- **`easing`:** `smoothstep(t)` and `smootherstep(t)`; the factories `power(exponent)`, `back(overshoot = 1.70158)`, `elastic(amplitude = 1, period = 0.3)` and `bounce(bounces = 3, restitution = 0.5)`, whose defaults reproduce `easeInBack`, `easeInElastic` and `easeInBounce`; the combinator `easeOutIn(easing)`; `cssLinear(stops: readonly LinearStop[])`, CSS `linear()` per CSS Easing Level 2; `toCssLinear(easing, options?: CssLinearOptions)`, which turns any easing into a `linear()` string within a `tolerance` (default `0.001`; Ramer–Douglas–Peucker, rounding included) from `samples` intervals (default `1000`, at most `2 ** 24`); and `spring().velocity(time)`, the exact speed, to retarget a moving spring without a jump. New types `LinearStop` and `CssLinearOptions`.
- **`math`:** `allocate` gains an overload for a `total` typed `number | bigint`.

**Safety: prototype pollution.** These helpers read their options, optional fields or array slots with plain property access, so a value planted on `Object.prototype` (or `Array.prototype`) was honoured. They now read own (or deliberately inherited, such as class getters) properties only, as the rest of the library already did; the shared reader also recognises a planted `NaN`, and a hole never reads a planted value.

- **Bypasses:** `isUrl` (a planted `protocols` list accepted `javascript:` URLs), `isSafeUrl` (a hole in `protocols`, the same), `parseJson` (a planted `proto: 'ignore'` turned the `__proto__` check off), `matchPath`/`compilePath` (with `Object.prototype[0]` planted, every path matched every pattern), `withBase` (`withBase('evil.example/x', '//')` gave a protocol-relative `'//evil.example/x'`).
- **Poisoned caches and merged keys:** `memoizeAsync`, `createBatcher`, `memoize`, `@memoize` (also bare) and `defaultMemoizeKey` (a planted `cache`, `resolver` or `key`, or holes: `[, 1]` got the cached result of `['planted', 1]`); `fromBase32`, and `fromBase64` without a native decoder (`fromBase64('aGk=')` gave `[0, 0]`); `parseNumber` (planted Intl options poisoned the symbols cached for a locale for good); the `format` helpers' formatter memo (`formatNumber(1, {})` printed `'1.00'` after a call with `minimumFractionDigits: 2`).
- **Planted signals, timings and limits:** `sleep`, `retry`, `pollUntil`, `mapWithConcurrency`/`mapSettledWithConcurrency`/`filterWithConcurrency`, `createLimiter`, `createQueue` and `Queue.add`, `createRateLimiter`, `Batcher.load`/`loadMany`, `waitFor`, `mapConcurrent`, `throttle`, `debounce`, `@debounced`, `@throttled`, `@retryable` (whose options copy now has no prototype, so an own `__proto__` key from `JSON.parse` stays a key), `diffSequences`/`longestCommonSubsequence` (`maxEdits`), `eachDayOfInterval`, `formatDuration`, `toISOStringLocal`, `spring`, `fuzzyMatch`/`fuzzySearch`. `createLimiter` and `createRateLimiter` called a planted `next` as the next task (a process crash); the shared abort listener's options have no prototype (a planted `signal` made every helper given a signal reject).
- **Output:** every `format*` helper and `pluralRule` (`locale`, `display`, `decimals`, `type`, `style`, `suffixes`, and a missing suffix category read from the prototype), `isHexColor` (`alpha`), `toRgba` and the colour helpers taking `{ r, g, b }` (an inherited `a` made every colour translucent), `getJwtExpiration`/`isJwtExpired` (`exp`), `toCsv` and `formatList` (a planted row or cell written out).
- **Holes and out-of-range reads:** `median([])` gave a planted `4` (also `ticks`, `decimalPlaces` and the rounding helpers), `divisors(1024)` listed `2048`, `mergeIntervals` returned `[]` so `findGaps` ignored every busy interval, `formatDate` wrote `Object.prototype[1]` for every token, a planted weight won every `weightedRandom` draw, and `SearchIndex#addAll` indexed a planted document; likewise `first([])`/`last([])`, `orderBy`, `highlight`, `dedent`, `trimChars`, the emitter, `anySignal`, `mergeAsync`, `SeededRandom.restore`, `isEqual` (Map keys and Set members) and helpers of every other module taking arrays. Where an element is required, a hole throws the existing `TypeError`.
- **Other planted fields:** `validate` hooks (a planted `missing`, `handlesMissing` or `score` made every parse throw, a planted `issues` failed every valid Standard Schema result inside a schema), `isEqual`/`isMatch` settings (a planted `customizer` made every comparison throw, `absentUndefined` made `isEqual({ a: undefined }, {})` true), `isShape` (`exact`), `deserializeError` and `defineError` (`code`, `status`), `formatError` (`exit`: it printed nothing), `evolve` (ran the `__proto__` setter), legacy decorators (`kind`).
- **A `get` or `set` key on `Object.prototype`** made every `Object.defineProperty` throw: `deserializeError` and `toError` broke their never-throw promise, `defineError` classes could not be created, and `safeStringify`/`serializeError` turned objects with a `toString` or `valueOf` key into a `[Throws]` marker. It also broke the `objects` writers (`pick`, `setPath`, `applyPatch` and others), `memoize`, `throttle`, `debounce`, the decorators, several `async` factories and `validate` object schemas; a planted `value` or `writable` broke every `cache` factory. Every descriptor now gives all four attributes, retried without a prototype when one is inherited.

**Safety: denial of service.** Out-of-memory aborts (which no `catch` stops), hangs and super-linear time on hostile sizes:

- **Shared values (`guards`, `validate`):** `explain` with `isLazy`, `lazy` parsers and the JSON guards (`isJsonValue` and friends) walked or reported an object held in several places once per path: exponential in the depth of the shared objects (20 levels gave a million issues, 40 ran out of memory; YAML aliases build such values). An invalid object is now reported at its first path, with one `Invalid value (same object as reported at another path)` issue at each other path, and a valid one is walked once, also when a guard or check explains or parses again at every level. So is a shared `isMatching` pattern (30 levels ran out of memory). A foreign Standard Schema wrapping a parser in a recursive lazy schema reported in full on every fast parse (1,600 levels: 51 s, now 0.2 s).
- **Shared values (`objects`, `errors`, `functions`):** `safeStringify`, `serializeError`, `stableStringify`, `hash` and `defaultMemoizeKey` (`memoize`, `memoizeAsync`) converted or wrote a shared container once per path (26 levels aborted the process). Each now handles it at most once per depth, with identical output (memo keys past a budget write repeated objects as references), and too long a text throws a `RangeError` at once. `getErrorMessage`, `toError` and the error descriptions stop at a million values; an `errors` array shared by many errors is walked once. `matchWith`, `matcher`, `anyOf`, `capture`, `captureAs`, `cons` and `active` tested a shared pattern once per path (30 levels: minutes, now 43 ms), and with a capture doubled the capture list before throwing.
- **Sparse arrays of length `2 ** 32 - 1`:** `stableStringify`/`hash` (an abort, reachable through `setPath` with a user index), `safeStringify`/`serializeError` (now an `Invalid string length` marker), `applyPatch`, `isMatch`, `defaultMemoizeKey`, `shallowEqualArgs`, `cons`, `toCsv` rows, `formatList`, every helper taking a locale list, the `errors` helpers, `computed` sources, `anySignal` (hours, now 50 ms), `arrayOf`/`asArray`/`asList` (120 s and 4 GB, then an abort), the JSON guards, `isArrayOf`, `isOneOf`, `dedent`, and the statistics (`sum`, `average`, `variance`, the median family, `dot` and others), which now return `NaN` at the first hole. Each visits the elements present or fails at the first hole.
- **Huge counts and lengths:** `colorSteps` with a count of `2 ** 32`, `isEmpty(new Uint8Array(4e7))`, `hash` of large typed arrays (4e7 bytes: 4 s and 2.8 GB, now 256 ms), `randomString(1e7)`, `fuzzySearch` with a `limit` (1e6 matches ran out of a 256 MB heap), JWTs of 1e8 dots, `integerSqrt` of a million-digit bigint (over 10 s, now 0.2–1.2 s), `parseBytes` with huge exponents (1.3 s, now 7 ms), the binary searches on array-likes longer than `2 ** 32` (endless at `Infinity`).
- **Long strings:** `removeDiacritics`, `toSlug`, `tokenize` and the default tokenizer of `createSearchIndex` took seconds on long runs of combining marks (`normalize` is quadratic in a run): runs longer than 30 marks are normalized 30 at a time (the Stream-Safe Text Format of UAX #15), so 100,000 marks take about 2 ms. The grapheme helpers overflowed the stack on a few million code units of `'\r\n'` or `'é'`, and the padding and capitalizing ones split a whole CJK text (10 million characters ran out of memory); `truncate` segmented all of a non-Latin text, fuzzy matching a target holding `Σ` or `İ` was quadratic, and `isSemver`, `isSlug`, `isCreditCardNumber` and `parseDuration` overflowed the regex stack. `normalizeUrl` was quadratic in removed query keys (10,000 `utm_*` keys: 36 s).
- **Process abort:** Node 26 aborts the process on the first setter of a URL it cannot parse back (`http://éxn--a/`), which `normalizeUrl` always calls: such a URL is now rejected.
- **Queues and listener lists:** every `async` helper taking a signal, the queues and semaphores, and `waitFor` added one abort listener per waiter, which Node scans on every add and remove (30,000 waiters on one signal: 6–19 s, now 20–95 ms): one listener per signal is shared. Semaphore queues, `fromEvent` reads, `mergeAsync`, `interleave` and `mapConcurrent`'s read-ahead (2–8.4 s for 40,000–100,000 items, now 12–76 ms) are linear, and the emitter's `off` is O(1) (100,000 concurrent `waitForEvent` hung). `SearchIndex#replace`, or `remove` then `add` of the same id, cost grew with the index (about 170 µs at 10,000 documents): about 1 µs at any size now. Notifying many histories of one store, `isEqual` on Maps with object keys (16,000 entries: 2 s, now 0.1 s) and `verifyJwt`'s `aud` check were quadratic; `persistStore` deserializes without a reviver, iteratively (4.8 MB: 9–13 s, now 1.2–1.4 s).

**Fixed: state after a throw or re-entrant call.** A stack overflow, a throwing getter or clock, or a callback calling back in, left these broken for good:

- **`store`:** a notification that overflowed left the notifier notifying (no listener ran again), and a batched change that overflowed was skipped by later batches; `undo`, `redo` and `history.batch` left their flags set when recording threw (no later change became a step, or all merged into one), a history whose `getState` threw kept old counts, and an `undo` called by a listener during another recorded a duplicate step. A derived store skipped the next change back to its last notified value after a notification or its `equals` threw. `persistStore` took a failed `getItem` for an empty storage and skipped a later removal (a token kept after "remember me" was turned off), and with `sync` dropped reactions to another tab when a listener threw.
- **`async`:** `createCircuitBreaker` stayed half-open, rejecting every call, when the clock threw as it reopened. `createSemaphore` and `createKeyedMutex` let a late abort of a request granted while its listener was being added report the lock idle: the keyed mutex then gave a key two holders, as it did after a late abort whose listener could not be removed, when an option getter released and re-took the key, or when a timed-out request's late idle report deleted the key's newer lock. A semaphore left lighter requests waiting with free permits when the head request's signal threw while being added; `createQueue` stopped listening to its signal when a task aborted during its registration. A signal calling its listener while it is being added leaked permits, ran aborted tasks or broke waiters; a native promise with an own throwing `then` (or `constructor` getter) lost a limiter or queue slot, leaked a permit, or left `createBatcher` and `mapConcurrent` pending: it is followed as `await` does. **`Queue#add({ signal })`:** a signal that could not drop its listener and aborted after the task had started rejected the task's promise, losing its result.
- **`iterables`:** `mapConcurrent`, `bufferTime` and the stream readers hung when the source's own `next()` aborted the signal (or fired `bufferTime`'s timer); readers given a signal read a result's `then` twice or cancelled a source twice; `mergeAsync` hung on a close result whose `then` changes between reads.
- **Caches and indexes:** an interrupted `createBiMap` set left half a pair; an interrupted `createTrie` set or delete corrupted keys (`cartography` read as `carttography`); an overflow while removing a `SearchIndex` document made every later prefix search throw.
- **Memos:** an overflow while lazy guards and `validate`'s lazy parsers released their memos, or restored their shared depth, kept stale verdicts and outputs for later checks (a tree made invalid still passed): an outermost check or parse releases what was left. A throw while building the named-colour table made later lookups miss; an overflow while checking `Math.sumPrecise` disabled it.
- **`random`:** one throwing `TextDecoder` constructor broke every later ASCII `randomId`; a `getRandomValues` calling `randomId` with another alphabet made the outer call serve that alphabet; `createUuidv7` with an injected `random` calling the generator gave the outer id the inner id's bits.

**Fixed.**

- **`angleDifference`** (and `lerpAngle`) gave a rotation a full period off, outside `(-period / 2, period / 2]`, when the angles differed by exactly a half turn below zero plus a subnormal: `angleDifference(9678326661783996, 5e-324, 24)` was `-36`, now `12`.
- **`throttle(fn, wait, { leading: false, trailing: true })`** never invoked `fn` while calls kept coming faster than its timer could fire (during a long synchronous loop): each late call dropped the pending one. The first call after a window now performs the overdue call, once per window, like lodash. **`debounce`** with `maxWait` could run `fn` up to `2 * wait - maxWait` late after a `flush()`.
- **`createEmitter`** called listeners with its internal registration record as `this` (a listener could reactivate itself); `this` is now `undefined`.
- **`isEqual`** threw comparing a `Map`, `Set`, `Date`, `RegExp` or `DataView` with a `Proxy` of one (or an object faking its tag), and was order-dependent for the other built-ins; both sides must now be the same kind of built-in. Binary data of different kinds behind a forged prototype no longer compare equal. Plain objects of another realm are plain for the other `objects` helpers too, and detached buffers act as empty ones.
- **`isError`** trusted the `'[object Error]'` tag for objects of other realms or with a `null` prototype, so a fake `Symbol.toStringTag` passed; it now uses `Error.isError` where the runtime has it.
- **`guards`:** `isTypedArray` accepts `Float16Array`; `isKeyOf` narrows a numeric key to its number and string forms; a lazy guard's memo shared one verdict between an object checked inside `isDiscriminatedUnion` and elsewhere; `isIntersection` merged two paths with the same text.
- **`zip` and `interleave`** read a non-object `next()` result as `{ value: undefined }` and kept going (an endless loop on an infinite iterator); like `for...of`, they now throw a `TypeError`. The async helpers accept a function as an iterator result, as `for await` does; `parseSSE` ignores a `retry` that is not a safe integer.
- **Floating point (`math`):** `weightedAverage` is correctly rounded (it was an ulp off in about a third of cases: `weightedAverage([1, 2], [1, 3])` gave `1.7500000000000002`) and no longer overflows to `Infinity` for huge values with a finite mean. `nthRoot` is within an ulp (it was up to 67 off for huge or tiny values) and returns exact roots exactly (it missed about half). `toRadians`, `toDegrees` and `zScore` no longer overflow in an intermediate step; `percentage(1, 3)` is `100 / 3`; `randomIntBetween(-MAX, MAX)` no longer always returns `MAX` (or `NaN`); `weightedRandom` accepts finite weights whose total overflows; `range(0, 2e15 + 1, 1e15)` keeps its last item. Numeric strings take the right special paths (`modulo(-1, '3')` was the string `'-13'`); `modulo(6n, -3n)` was `-3n`, now `0n`.
- **`date`:** `diffInWeeks`, `diffInMonths`, `diffInYears` and `intervalToDuration` came up one unit short where clocks went back across midnight. `roundToNearestMinutes`, `startOfHour`, `endOfHour`, `startOfMinute`, `endOfMinute` and `eachOfInterval` moved a slot skipped by a spring-forward gap (on the Chatham Islands `startOfHour(03:50)` gave `02:00`): it gives the end of the gap, as documented. `endOfHour` ran past the next hour where clocks went back to a full hour. `parseDate` reads back `'YYYY[0]MM'`.
- **`parseDuration`** read decimals through a binary fraction: `'1.001s'` was `1000.9999999999999` ms, now `1001`.
- **`cubicBezier`** stopped one Newton step early (errors up to about 1.4e-12); it is now within a few ulps, like `bezier-easing`.
- **Text:** `toTitleCase`, `toPascalCase`, `toCamelCase`, `toStartCase`, `toTrainCase`, `toSentenceCase` and `toDelimitedCase({ case: 'capital' })` upper-cased 83 letters instead of title-casing them (Georgian words started with a Mtavruli capital, Greek letters with ypogegrammeni became two letters), and skipped words starting with a modifier letter (`'ʻiolani'`); every lower-case letter now matches Python's `str.title()`. `wordWrap` broke lines at no-break spaces. `stripHtml` ended a script at a `</script>` inside `<!--` and removed tags inside `<title>` and `<textarea>`; it now reads them as browsers do (as parse5 on 600,000 fragments). Fuzzy search never matched an upper-case Greek word ending in `Σ`, and `tokenize` applied Final Sigma across words.
- **`url`:** `normalizeUrl` was not idempotent on an escape after a stray `%` (`%%611`) or an escaped `file:` drive letter; `getQueryParam(url, 'ids[]')` never matched; `withQuery` with `arrayFormat: 'brackets'` left a smuggled `ids[][]` pair next to the new `ids[]`.
- **`encoding`:** `verifyJwt` accepted a token without an `iss`/`aud` claim when `issuer` or `audience` was a sparse array (`[, 'api']`); it now throws a `TypeError`. `toCsv` wrote a row whose only cell is a hole, an empty last row, and an empty first field before a U+FEFF delimiter as nothing (lost by `parseCsv`): each is `""` now.
- **`cache`:** with fractional `sizeOf` sizes, `totalSize` drifted (an emptied cache reported `2.8e-17`); it is exact. It became `NaN` past `Number.MAX_VALUE`, which stopped enforcing `maxSize`.
- **`store`:** `undo()`/`redo()` inside `batch()` recorded the listeners' reactions as a new step; `persistStore({ sync: true })` tabs could keep rewriting each other's value, or roll back to an older one on a late storage event (2,223 of 5,000 simulated runs).
- **Also:** `deserializeError` cut chains deeper than the call stack (about 6,200 levels); `formatError` printed a stale stack header as a frame; a static `@bound` or `@lazy` value read on a class leaked into subclasses; `@log` and `@measure` threw on a native promise with a throwing `then` getter; `createQueue` and `createRateLimiter` kept listening to their own signal (one per request was never collected); `createBatcher` kept its timer running after every key left; `safeStringify` and `serializeError` dropped a function's `toJSON` and boxed replacer keys, which `JSON.stringify` writes.
- **Standard Schema:** a foreign validator returning a falsy `issues` other than `undefined` (`null`, `false`) crashed `parse`; any falsy `issues` now means success, as the spec says.
- **`curry(null)`** threw the engine's error reading `fn.length` instead of the library's `TypeError`; **`once`** and **`before`** release `fn` after their last call, so its closure can be collected.
- **Non-number options** were converted before being rejected (calling `valueOf`, or joining a long array for minutes): `throttle`, `debounce`, `cubicBezier`, `spring`, `isNumberInRange`, `isIntegerInRange`.

**Faster.** Steady-state results are identical to 1.5.0 (checked on random and edge inputs); the most visible changes:

- **`emitter`:** unsubscribing and removing `once` listeners is O(1) amortized, also during an emit (it rebuilt the list, and copied it during an emit): 1,000 `once` listeners and an emit are 75× faster, 1,000 unsubscribes 39×.
- **`date`:** reading a timestamp no longer allocates a `Date`: `isBefore`, `compareAsc`, `minDate`, the `diffIn*` helpers and the other comparisons are 5–20× faster.
- **`objects`:** null-prototype records and plain objects of another realm (iframes, `vm` contexts, `fetch` bodies under Jest) went through brand checks that each threw: `isEqual` and `deepClone` of 100 such records are 87–142× faster, `deepFreeze` 10×. `isEqual` on typed arrays is 26× faster (1.3× faster than es-toolkit), on Maps and Sets of primitives about 2×; `isEmpty` on primitives up to 229×; the merge helpers and `pick` 1.2×.
- **`math`:** `covariance`, `correlation`, `linearRegression`, `rootMeanSquare`, `skewness`, `kurtosis`, `standardize` and `softmax` 5–14× on 10,000 values, `mode` 2.2×, `weightedAverage` 2×.
- **`strings`/`search`:** kana, CJK punctuation and Hangul skip `Intl.Segmenter` (`reverse`, `truncate`, `stringWidth`, `mask`, `wordWrap` on Japanese or Korean text 2–80×), `dedent` 2×, `fuzzySearch` 1.8–4.2×.
- **`easing`:** the `easeInOut*` curves 1.5–1.8× (bit-identical); `cubicBezier` solves with Halley's method instead of Newton's (2–3 steps instead of 3.5–5.5), up to about 1.6× faster, ahead of `bezier-easing` on every curve benchmarked.
- **`color`:** the 8-bit to linear-light table is a typed array built on first use (`contrastRatio` 1.6–2.3×, `deltaE` 1.2–1.6×, `toOklch` 1.4×), and `toColorName` looks exact matches up in a reverse map (14×).
- **`encoding`:** `sha256`/`hmacSha256` compute the message schedule in a 16-word ring (1.3–1.5×), `decodeJwt`/`verifyJwt` skip the `JSON.parse` reviver when no polluting key can be present (1.4–1.8×), `encodeUtf8({ fatal: true })` uses the native `isWellFormed` (3.4×).
- **Others:** the async iterable helpers on sync sources 1.2–1.4× (one `await` per item instead of two; items now arrive one microtask sooner), `isRecordOf` 1.8–2.3×, `zipObject` with up to 16 keys 1.65–3.2×, `debounce`/`memoize` creation 1.5×.

**Behaviour changes** beyond the fixes above:

- **Derived stores** (`select`, `computed`) notify when their value changed back after the intermediate value was read (1.5.0 skipped it, leaving whoever read it with that value), so subscribers can be told of the value they saw last. A listener that asks for a value again while another refuses it now loops until the round limit (`RangeError`): listeners should ignore calls whose value did not change.
- **Limits** instead of aborts or hangs: `arrayOf`, `asArray` and `asList` reject more than 65,536 holes in a row with one `Expected at most 65536 holes in a row` issue at the first; `applyPatch` throws a `JsonPatchError` on an array with holes longer than `2 ** 27`; `colorSteps` throws a `RangeError` for a count above `2 ** 32 - 1`, `toCssLinear` for `samples` above `2 ** 24`, `isMatching` for an array pattern of more than `2 ** 24` elements.
- **Reports and errors:** `explain` reports a run of holes once, at its first index; `ValidationError` lists the first 100 issues, then how many more; a fast parse through a foreign Standard Schema wrapper gets one generic issue. `getErrorMessage`, `toError`, `serializeError` and `formatError` describe a value whose JSON passes a million values by its tag; `formatError` and `getErrorChain` skip the holes of an `errors` array (labels keep the real index) and print an `errors` array shared by several errors once; `defineError` reserves only the keys `Object.prototype` really defines.
- **Inputs:** `match` no longer takes an object or function tag by its string form (`{ kind: ['circle'] }` reached the circle handler); only `_` handles it. `anySignal` reads an array by its own keys, not its iterator. `dedent` called with an array throws a `TypeError` on a hole or a non-string element. `parseDuration` reads millions of tokens, throwing its `TypeError` for an invalid input instead of a `RangeError`. `formatOrdinal` requires a string `suffixes.other`; `formatList` throws on a hole. `meetsContrast` (`largeText`), `toColorName` (`nearest`), `toHex` (`alpha`), `persistStore` (`sync`), `createLRUCache` (`updateAgeOnGet`) and `createMultiMap` (`unique`) throw a `TypeError` for a non-boolean, and `createLRUCache` for a clock returning `±Infinity`. `isError`, and so `createBatcher`, no longer takes a `null`-prototype object tagged `Error` for an error.
- **Others:** `tryParseUrl` returns `undefined` for a URL Node cannot parse back; memo keys of deeply shared arguments differ (a miss at worst); a removed `SearchIndex` document's ids and terms stay until the next vacuum. A `Map`, `Set` or buffer whose prototype was set to `null` is treated as the record it looks like by `clone`, `deepClone`, `isEqual`, `isEmpty` and `deepFreeze`; a run of more than 30 combining marks may normalize differently from the native `normalize` (marks are not reordered across the cuts); `isRecordOf` visits the keys an object had when the check started.

**Package size:** the runtime budget was raised from 154 kB to 160 kB gzipped; the runtime total is about 158.4 kB gzipped (was 146.9 kB in 1.5.0). Module-level `new RegExp(...)` calls, which esbuild keeps in every bundle, are now literals: most `strings` and `url` helpers shrink by 60–250 B gzipped. The fixes add a few dozen bytes to the helpers that now read options safely; the largest growths are `isMatching` (about +1.2 kB: it now bundles `isLazy`, to match shared patterns linearly, and `matcher`, which uses it, goes from 4.0 to 5.7 kB), the easing additions (about +1.8 kB), the `validate` parsers (about +0.6 kB each: hole limits, linear reports, memo release), `memoizeAsync` (+0.7 kB, of which `defaultMemoizeKey`'s +0.4 kB buys keys of shared and sparse values), the `functions` pattern helpers (about +330 B), `createEmitter` (1.4 to 1.8 kB: O(1) removal and `off`), `toCsv` (1.2 to 1.5 kB: sparse rows), `weightedAverage` (+285 B), `nthRoot` (+223 B) and `fuzzyMatch`/`fuzzySearch`/`tokenize`/`createSearchIndex` (+260–320 B).

## 1.5.0

A completeness, safety and performance pass over `store` and `cache`, driven by a fresh mutation run (every surviving mutant is now killed by a test or documented as equivalent) and by benchmarks:

- **`store`: `batch(fn)` (new).** Holds back the notifications of every store `fn` changes until it returns, then notifies each changed store once, in the order of its first change: updating several stores (or one store several times) costs one notification per store, and subscribers never see a combination `fn` only passed through. States change at once, batches nest, `select`/`computed` stores notify once even over several changed sources, a machine's listeners see the last snapshot, and a history records one step. Errors of `fn` and listeners are rethrown once everything has notified; a thenable result throws a `TypeError`.
- **`store`: `persistStore({ sync: true })`.** Follows the `storage` events of other tabs: what another tab writes under the key is hydrated as at startup (deserialized, migrated, merged) without being echoed back, what this tab's listeners change in reaction is written, and a key removed elsewhere leaves the state as it is. Does nothing where there are no storage events.

- **Faster construction.** Every `cache` structure is now built from a shared prototype (created on first use) instead of `Object.defineProperties` on each instance: creating a priority queue costs 91 ns (was 530 ns), a ring buffer 112 ns (660 ns), a deque 195 ns (575 ns), an LRU cache 266 ns (580 ns), which matters for short-lived queues and per-request caches. `createStore` costs 74 ns (was 305 ns): the notifier that `createHistory` needs is attached with an unforgeable private field instead of a `WeakMap`, which also spares the garbage collector an ephemeron per store.

- **`date`:** interval sets for scheduling: `mergeIntervals` (O(n log n), half-open like `intervalsOverlap` unless `inclusive`), `intersectIntervals`, `subtractIntervals` and `findGaps` (free slots, with `minDuration`). `addBusinessDays`/`diffInBusinessDays` take `holidays` and a custom `weekend` (`[5, 6]`), staying O(1) without holidays and unchanged without options; `isBusinessDay` is new. `setParts` (date-fns `set` with the module's 1-based `month`, clamping the kept day), `closestTo`, `fromUnixTime`/`getUnixTime`. `Interval` is now generic.
- **`color`:** `colorScale`/`colorSteps` (multi-stop gradients through `mix`, with `space`/`hue` and an optional `domain`), `isCssColor`, opt-in CSS named colours (`parseNamedColor`, `toColorName` with exact or `nearest` matching in OKLab; the table is only bundled by those two), `saturate`/`desaturate`/`grayscale`/`rotateHue`/`complement` (`{ space: 'hsl' | 'oklch' }` like `lighten`), `rgbToHsv`/`hsvToRgb`.
- **`store`:** `computed(stores, compute, { equals })`, a read-only store derived from one or more stores: it subscribes only while observed and is glitch-free (a diamond recomputes and notifies once per change). `persistStore` hydrates synchronously from `localStorage` or any sync storage (`version`/`migrate`, `partialize`, `merge`, debounced writes skipped when unchanged), writes a migrated state back at once, never throws on missing or corrupt storage, and drops `__proto__` keys and `constructor.prototype` objects from what it reads.
- **`cache`:** `LRUCache.getOrSet(key, factory)` (cache a promise for single-flight loading) and `createDeque`, a ring-buffer double-ended queue with O(1) operations at both ends, `at(±i)` and an optional `capacity`.
- **`encoding`:** `toBase32`/`fromBase32` (RFC 4648, base32hex, Crockford; strict decoding), `timingSafeEqual`, `decodeJwt` (reads a token **without verifying it**; strict base64url, JSON objects only, prototype keys removed) with `getJwtExpiration`/`isJwtExpired`, and RFC 4180 CSV: `parseCsv` (linear time, quoted fields, any line ending, BOM, `header` records with a null prototype, where a field missing from a short row is absent, so memory stays linear in the input, and `strict` rejects ragged rows with line and column) and `toCsv` (arrays or records; opt-in OWASP `formulaEscape`, which quotes every field and also catches formula signs behind leading white space and their full-width forms), with `parseCsv(toCsv(rows))` giving back the rows.
- **`url`:** `parseCookie` (first occurrence wins, never throws, null prototype) and `serializeCookie` (RFC 6265 grammars, so `;` or CRLF injection throws; also rejects the `SameSite=None`/`Partitioned`/`__Host-`/`__Secure-` combinations browsers drop), `normalizeUrl` (idempotent; opt-in `stripHash`, `stripWww`, `sortQuery`, `removeTrailingSlash`, `removeQueryParams`, `forceHttps`) and `tryParseUrl` (`URL.parse` for Node 20).
- **Fixed (`math`):** `variance` and `standardDeviation` now use the corrected two-pass algorithm instead of Welford's, which lost digits on
  data far from zero (`variance([1e15 + 1, 1e15 + 2, 1e15 + 4, 1e15 + 8])` was `7.1171875`, it is exactly `7.1875`); they still overflow only
  when the variance itself is beyond the doubles. `inverseLerp` (and so `mapRange`) keeps the sign of an infinite result when the range is a
  few subnormals wide.
- **Changed (`math`, `date`):** `clamp` and `clampDate` no longer throw when the bounds cross (`minimum > maximum`): the minimum wins, as in CSS `clamp(MIN, VAL, MAX)` and lodash, since layout code routinely computes bounds like `[0, containerWidth - panelWidth]` that cross before the first layout. A `NaN` bound still throws a `RangeError`.
- **Package size:** existing helpers cost what they did; the runtime budget of `yarn check:size` is now 124 kB gzipped for all 22 modules (was 92 kB) and the packed budget 500 kB (was 350 kB); the declaration check (`yarn check:types`) allows 66,000 type instantiations (was 60,000) for the new public types.

## 1.2.0

New helpers, each reviewed adversarially against its spec or reference implementation:

- **`encoding` (new module):** strict base64/base64url (`toBase64`, `fromBase64`, accepting exactly what `isBase64` accepts), hex (`toHex`, `fromHex`), WHATWG-exact UTF-8 (`encodeUtf8`, `decodeUtf8` with `fatal` and `stripBom`) and a synchronous `sha256`/`sha256Hex`, without `Buffer`; native `toBase64`/`fromBase64`/`toHex`/`fromHex`/`TextEncoder`/`TextDecoder` are used where they give identical results.
- **`async`:** `createBatcher`, DataLoader-style batching of every `load(key)` made until the microtask queue drains (after any number of `await`s): deduplicated keys, `maxBatchSize`, `delay`, per-key `Error`s, a clear `TypeError` for malformed results, per-call `signal`s with one abort listener per signal, and no cache by default (DataLoader's unbounded default leaks and goes stale); pass `cache: true` per request or an LRU, with single-flight requests, uncached errors and `clear` / `clearAll` / `prime`.
- **`validate`:** `parseEnv(schema, env?)` reports every missing or invalid environment variable at once, one per line, and no part of a value can reach the error, by construction: fixed messages and paths, other libraries' and custom messages become `Invalid value`, and a schema that throws is reported by its error name. Blank values count as unset by default, `prefix` maps `PORT` to `APP_PORT` / `VITE_PORT`, `strict` reports undeclared prefixed variables, and the output has a `null` prototype.
- **`url`:** typed route patterns: `matchPath` and `compilePath` (`/users/:id/:tab?`, `/@:handle`, `/files/*path`, optional segments), with parameters inferred from the pattern. Matching is linear in the pathname without a regular expression, decodes segments safely, rejects dot segments and traversal through encoded separators, and folds ASCII case only; building encodes values and guarantees the path matches back to the same parameters.
- **`objects`:** `replaceEqualDeep` (structural sharing like TanStack Query, linear on shared subtrees, safe on cycles) and JSON Patch (RFC 6902/6901): `createPatch`, an immutable, all-or-nothing `applyPatch` with structural sharing and prototype-safe pointers, `JsonPatchOperation` and `JsonPatchError`.
- **`date`:** IANA time zones without a bundled database: `isValidTimeZone` (narrowing to `TimeZone`), `getTimeZoneOffset`, `getZonedParts`, `fromZonedTime` (Temporal's disambiguation, and an exact round trip through `offset`), `formatInTimeZone` (the `formatDate` tokens plus `Z`/`ZZ`), `startOfDayInTimeZone` and `endOfDayInTimeZone`; they accept IANA names or `±HH:MM` offsets, never depend on the runtime's zone, and match Temporal on every transition of every zone from 1800 to 2100. `getCalendarMonth(year, monthIndex, { weekStartsOn, fixedWeeks })` gives date-picker grids.
- **`random`:** `uuidv7`/`createUuidv7` (RFC 9562, strictly increasing), `ulid`/`createUlid` (monotonic, throwing on overflow as the spec requires), and `uuidv7Timestamp`/`ulidTimestamp`; the clock and random source can be injected, and the defaults always use the CSPRNG.
- **`strings`:** `compareNatural` (a deterministic natural-order comparator: digit runs of any length, a total order, optional `ignoreCase`), `truncateMiddle` (grapheme-aware, with a `position`) and `stringWidth` (terminal columns: Unicode 17 East Asian Width, emoji sequences, ANSI escapes stripped; matches `string-width` on every assigned code point).
- **`math`:** `sumPrecise` (TC39 `Math.sumPrecise` semantics: exactly rounded and overflow-safe), `movingAverage` (exact running sums: no drift), `toSignificant` (significant figures, rounded as written) and `histogram` (d3-style bins with exact counts and correctly rounded edges).
- **`store`:** `createMachine`, a tiny typed state machine (states, context and event payloads inferred from the config; guards, context updates, `can`/`matches`, queued events from listeners, `useSyncExternalStore` snapshots), and `createHistory`, undo/redo for any store (`batch`, `coalesce` with an injectable clock, `limit`; a `createStore` change and its listeners' reactions are one step).
- **`color`:** OKLab/OKLCH: `toOklab`, `toOklch`, `oklabToRgb`, `oklchToRgb` (CSS Color 4 gamut mapping), `inGamut`, `toCssOklch`; `parseColor` reads `oklab()`/`oklch()` (as Tailwind v4's palette is written), `mix` takes `{ space: 'oklab' | 'oklch', hue }` like CSS `color-mix`, and `lighten`/`darken` take `{ space: 'oklch' }`. Defaults are unchanged; the string-parsing helpers grow by about 1.1 kB for the new syntax.
- **Fixed (`date`):** the day boundaries (`startOfDay`, `endOfDay`, `startOfMonth`…) of a day whose midnight fell in a DST gap that began the evening before (Toronto 1919), `endOfDay` when a day comes back hours after midnight (Alaska 1867), and `intervalToDuration`/`diffInMonths` across a skipped calendar day (Samoa 2011). Cached `Intl` formatters can no longer be corrupted by a polluted `Object.prototype`.
- **Fixed (`math`):** `average([MAX_VALUE, MAX_VALUE, MAX_VALUE])` returned `Infinity`.
- **Security (`url`):** `isSafeUrl`/`sanitizeUrl` and `buildQueryString`/`withQuery` read their options as own properties only: a polluted `Object.prototype.protocols` could make `isSafeUrl` accept `javascript:` URLs. The options of every `objects`, `strings`, `math` and `color` helper (`deepMergeWith`, `isMatch`, `flattenObject`, `sortKeys`, `mask`, `wordWrap`, `countSubString`, `variance`, `mix`, `toHex`, `getReadableTextColor`…), and of `isBase64`, ignore values inherited from `Object.prototype` (options from class getters or proxies still work).
- **Fixed (`url`):** `parseFormData` throws its own `TypeError` for an entry that is not iterable.
- **Types:** byte-returning helpers (`fromBase64`, `encodeUtf8`, `sha256`, `randomBytes`…) return `Uint8Array<ArrayBuffer>`, so their results pass to `crypto.subtle` and `Blob`; checking the declarations (`skipLibCheck: false`) now needs TypeScript 5.7+.
- **Tests** run in six time zones (Apia and Havana added, for skipped days and midnights); the size budget is 92 kB gzipped runtime and 350 kB packed.

## 1.1.0

Zod-like schemas, without the dependency:

- **`validate`: `parse` / `safeParse`** take a plain object of guards and parsers, return a typed output with unknown keys stripped, and report every issue with its path (`ValidationError`). Object schemas compile to specialized code on first use (falling back to a loop where `new Function` is blocked, e.g. by a CSP), and the bundled benchmarks parse nested records 1.6× faster than zod 4.
- **Strict coercion:** `asNumber`, `asInteger`, `asBoolean` and `asDate` reject what `z.coerce` silently converts (`''` → `0`, `'false'` → `true`, `null` → `0`, `'2023-02-29'` → March 1st, unsafe integers).
- **Combinators:** `withDefault`, `optional`, `nullable`, `transform`, `chain` (zod's `.pipe()`), `arrayOf`, `tuple`, `recordOf` (with an optional key guard), `union`, `discriminatedUnion` (direct variant lookup, tag first in the output; 1.25× faster than zod on the bundled event benchmark), cycle-safe `lazy` (recursive unions stay linear in the size of the value, and a value too deep to parse fails with an issue instead of a `RangeError`), `exact` (reject unknown keys), `partial`, `check` (zod's `.refine()`, with a message and a path for rules across fields), `withFallback` (zod's `.catch()`), `withError` (one message of your own in place of a schema's issues, for form fields), and `toParser` to hand any schema to a Standard Schema consumer. Every parser is a Standard Schema validator, and Standard Schema validators (zod, valibot, ArkType…) can be nested in a schema.
- **Real-world input:** `asArray` (a repeated query parameter is a string or an array), `asList` (a comma-separated list in an environment variable), `asBigInt` (64-bit ids beyond `Number.MAX_SAFE_INTEGER`), `blankAsUndefined` (an empty form field counts as missing) and `asJson` (JSON in an environment variable, pollution-safe); `issuesByPath` (`guards`) turns issues into per-field messages.
- **`url`: `parseFormData`** reads `FormData` (or `URLSearchParams`, or any `[key, value]` pairs) like `parseQueryString` reads a query string: a repeated field, such as a group of checkboxes, is an array instead of its last value.
- **`guards`:** `isDiscriminatedUnion` (direct variant lookup, with the tag added to each variant's type), `isIntegerInRange`, `isStringOfLength` and `isStringMatching` (stateless with `g`/`y` regexes). Their failures are explained without echoing the rejected strings.
- **Fixed:** `isArrayOf` and `isTuple` read the holes of a sparse array through a polluted `Array.prototype` or `Object.prototype`; holes are now always checked as `undefined`.
- **Faster:** `isShape` (and the object patterns of `isMatching`) compile to specialized code like `parse`, about 3.5× faster (2.9× faster than zod 4 on the bundled benchmark); `isUrl` recognises plain `http(s)` URLs without the URL parser, about 5× faster (2.4× faster than zod's `z.url()`), with every other URL going through the full check as before.
- **Fixed:** a recursive `isUnion` (through `isLazy`) whose members are told apart deep inside a value took time exponential in its depth, to check and to explain: each lazy guard now checks an object once per check, and `explain` reports the closest member only (a nested `isUnion` now scores as its closest member). A value nested too deeply to check is rejected (`Value is nested too deeply`) instead of throwing a `RangeError`.
- **Hardening (three review passes over every module, each fix with a regression test):**
    - **No hangs:** `countSubString` with a non-string needle, binary searches past 2^31 items, `parseJson` under a polluted `Object.prototype`, path readers on a `Proxy` that is its own prototype, and `mapConcurrent` on hand-written sources all terminate now.
    - **No blow-ups:** `isEqual`, `isMatch` and `diff` handle subtrees shared by many paths once (they were exponential); reporting an invalid deep `lazy` value and trimming non-Latin text are linear (they were quadratic); huge sparse arrays are walked by their elements.
    - **Hostile signals:** `async`, `emitter` and `iterables` helpers settle and clean up when an `AbortSignal`-like object's methods or `reason` getter throw, instead of crashing from a timer.
    - **Prototype pollution and frozen prototypes:** lookup tables, `Intl` options and parsed objects never read inherited values; `safeParse`, `setPath` and `unflattenObject` work under a frozen `Object.prototype`; `secureRandom` never serves bytes from a failed refill.
    - **Numbers and dates:** `roundToStep` is exact from 2^52, `averageBy([1e308, 1e308])` and `standardDeviation([-1e308, 1e308])` stay finite, springs settle at extreme ratios, and end-of-day/week helpers handle skipped and repeated midnights (Samoa, St. John's, Havana, Lord Howe).
    - **Clones:** `deepClone` keeps errors as real errors, resizable buffers resizable, and views that reach the end of one length-tracking.
    - **Types:** `pipe`/`compose` reject mismatched steps at compile time, `emitter` wrappers generic over the event map compile again, `retry` takes `PromiseLike`, and standard decorators accept methods that declare `this`.
- **Stricter inputs (may surface bugs in callers):** a few helpers now throw a `TypeError` instead of coercing nonsense: `clamp` with non-number bounds, `levenshtein`, `similarity`, `removeDiacritics`, `isPalindrome` and `countSubString` with non-strings, `mask`/`truncate`/`wordWrap` with non-string options, a `memoize` cache missing its methods, `mapKeys` returning a non-key, `typedFromEntries` and `parseFormData` given entries that are not pairs, and `createLRUCache` with a clock that does not return a number.
- **Package size:** the runtime budget of `yarn check:size` is now 72 kB gzipped (was 64 kB) for the new validation layer, and the packed budget 300 kB (was 280 kB) for the documentation the type declarations and `llms-full.txt` carry; per-helper import costs are listed in [docs/SIZES.md](./docs/SIZES.md).

## 1.0.0

Initial release of **tinkit** (`npm install tinkit`): strictly typed, zero-dependency, tree-shakeable utilities, published as ESM for Node 20.19+ and modern browsers.

### Modules

- **Data:** `arrays` (ordering, grouping, set algebra, combinatorics, Myers diff), `objects` (clone, merge, defaults, equality, immutable path updates, key-case transforms, stable hashing), `iterables` (lazy sync and async pipelines).
- **Validation:** `guards` (type predicates that compose into path-aware, [Standard Schema](https://standardschema.dev) validators), `validate` (linear-time string validators and a safe `parseJson`).
- **Text and URLs:** `strings` (grapheme-aware case, padding, trimming, truncation, escaping), `url` (query strings, safe URL editing and sanitising), `search` (fuzzy matching with highlight ranges).
- **Numbers, time and colour:** `math`, `date` (DST-safe arithmetic, durations, strict parsing), `format` (cached `Intl` formatting), `color` (CSS parsing, mixing, WCAG contrast), `easing` (CSS-accurate curves, springs).
- **Control flow and state:** `functions` (debounce, throttle, memoize, exhaustive `match`), `async` (retry, queues, rate limiting, single-flight memoization, cancellable concurrency), `cache` (LRU with TTL, priority queue), `emitter`, `store`, `random` (seeded and cryptographic), `decorators`.

### Guarantees

- **Hostile input:** path, merge, clone and query-string helpers never read or write through `__proto__`, `constructor` or `Object.prototype`; every regular expression runs in linear time; validators reject look-alike hosts and invisible characters; helpers whose cost grows with input size document it ([SECURITY.md](./SECURITY.md)).
- **Edge cases:** compensated sums, decimal-correct rounding, total orderings (`NaN`, `null` and `undefined` sort last), grapheme-aware text, wall-clock date arithmetic across DST changes, async helpers that leak no timers, listeners or unhandled rejections.
- **Bundles:** one ESM file per module, no code runs at import time (`yarn check:treeshaking`), a median of 450 B per imported helper ([docs/SIZES.md](./docs/SIZES.md)).

### Quality gates

Run by the pre-push hook (`yarn validate`): lint, formatting, type checking, 3,600+ tests in four time zones with 100% statement and branch coverage, fast-check property tests, every JSDoc `@example` executed against the build, a smoke test of the built package, size and tree-shaking budgets, a type check of the published declarations, and export resolution checks. Mutation testing (`yarn test:mutation`) and property stress testing (`yarn test:stress`) run on demand.
